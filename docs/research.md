## Annual bill first

USD 23,400 per year is a third-party reported median, not a vendor price. [Noon's 20 October report](https://www.noon.ai/blog/articles/424-culture-amp-pricing-2026) attributes that amount to 517 Vendr purchases. Vendr returned HTTP 403 during this run, so its underlying records were not independently inspected. Module mix, company size and a real ANZ customer invoice remain unverified. The comparison page uses no dollar amount.

## Scope and original sources

The [vendor export guide](https://support.cultureamp.com/en/articles/8438326-survey-export-options) documents Questions report CSVs. The [participant guide](https://support.cultureamp.com/en/articles/8384294-general-survey-participant-faqs) explains reporting minimums. The importer uses reviewed field mapping because the help page does not guarantee one universal header layout. Tests use fictional fixtures. No customer export was accessed.

Culture Amp already provides reports, action plans and benchmarking. This build replaces the owned operational record and follow-through work, not proprietary survey science, benchmark data, performance reviews or employee survey hosting. It requires no external network to use approved aggregate data. The product and public page must preserve that distinction.
