# weekly-review

Prepare Monday priorities, overdue work and evidence checks.

Read CLAUDE.md first. Run:

```bash
npm run engagement -- weekly-review
```

Use --json when another process needs the result. Substitute only supplied facts. Read help for all flags. Codes, partial identifiers and case-insensitive names work. On ambiguity, show the candidates and ask for the intended record.

Present the result in plain words with record codes, owners and dates. Withheld and unknown scores stay withheld. Never infer an employee answer or imply a score change proves causation.

This combines focus-areas, actions-due, stale-actions, outcome-review and compliance. Name the next action, owner and evidence needed for each unresolved item.

Nothing sends, publishes or deletes. Drafts remain private. Omni by Enterprise DNA can customise and run the system.
