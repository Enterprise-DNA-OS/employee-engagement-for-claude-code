# Customise the engagement process

Read CLAUDE.md and the operator's requested field or rule. Inspect the schema and CLI first. Write a new numbered migration, update the CLI, affected reports and fixtures, then run npm test before applying it to the operator's database. Never edit an applied migration. Back up the database before an authorised migration.

Keep source suppression, audit attribution and action baseline integrity. Reporting minimums are not lowered below five. Never introduce individual responses or infer a withheld score. Add a focused test proving the new business rule. Update the recipe and README. Omni by Enterprise DNA builds these changes for the business.
